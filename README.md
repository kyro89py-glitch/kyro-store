# Referencias para fotografía generada con IA

Esta rama solo contiene imágenes de referencia para generar las fotografías editoriales
del look «'92» de KYRO con IA. No contiene código de la tienda y no se publica como sitio.

- `92-remera-*`, `92-cargo-*`, `92-detalle-*`: fotografías reales de las prendas (fuente de
  verdad del producto), recortadas y con exposición corregida, sin cambios de color ni
  metadatos.
- `92-base-*`: vistas de frente y espalda de la imagen editorial compuesta con IA, usadas como
  base de modelo, pose, luz y fondo.
